# Microsoft Fluent 2

## When to use

Use when the same product must feel coherent across web, Windows, and mobile without pretending those platforms share every interaction convention. Fluent provides platform-specific component resources and accessibility-oriented design tools.

## What to extract

Compare the behavior required by the task with the platform's component guidance. Separate reusable intent and semantic roles from platform-specific interaction details. Use its focus-order and contrast resources as prompts for explicit checks, not as substitutes for testing.

## What not to copy

Do not transplant Microsoft branding or desktop conventions into a touch-first surface merely for consistency. A cross-platform system should preserve the user's expectations on each platform, not enforce pixel identity. Choose components that fit the project's existing stack before considering a new dependency.
