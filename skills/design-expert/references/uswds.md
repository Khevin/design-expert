# U.S. Web Design System

## When to use

Use for public-facing services that need coherent components, accessible behavior, and documented implementation choices. Its pattern library includes complex forms and language selection; its tokens connect design choices to code.

## What to extract

Trace a user task through the pattern, the selected components, and their accessibility guidance. Use the maturity model as a prompt to adopt a system deliberately rather than copying isolated widgets. Compare USWDS and GOV.UK when their service approaches reveal a useful tradeoff.

## What not to copy

Federal identity, jurisdiction-specific content, and public-service conventions do not automatically belong in a commercial product. Do not import the entire framework when the project already has a suitable system. Validate the chosen implementation rather than treating the source's reputation as a guarantee.
