# web.dev learning guides

## When to use

Use when a design decision depends on responsive behavior, browser capabilities, accessibility, or performance. The learning guides connect visual intentions to web implementation and testing.

## What to extract

Follow the relevant course rather than browsing the whole catalog. Turn a proposal into checks: what changes when space is constrained, how content remains usable during loading, and how interaction works without animation or a pointer. Use the accessibility course to guide implementation and test planning.

## What not to copy

A tutorial's sample layout, technology choice, or performance result is not evidence that the same choice fits this product. Verify current browser support and test representative content and devices. Prefer the project's existing implementation when it meets the requirement.
